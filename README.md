# Accountability App

A mobile-first productivity and accountability app for tracking tasks, custom goals, streaks, and leaderboard progress.

## MVP Features
- Email/password auth
- Basic profile
- Tasks
- Custom habit/goal tracking
- Progress logging
- Streaks
- Dashboard
- Leaderboard
- Public profile

## Stack
- Frontend: React + Tailwind
- Backend: FastAPI
- Database: Supabase/Postgres
- Hosting: AWS later
