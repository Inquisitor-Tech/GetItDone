KEY NOTES:

Backend:
  • Route → Controller → Service layer ensures separation of concerns
  • Prisma schema.prisma houses all data models; migrations/ auto-generated
  • JWT tokens: access (short-lived, 15min), refresh (long-lived, 7d)
  • Error middleware catches all thrown errors and returns standardized responses
  • Middleware stack: CORS → logging → auth (conditional) → validation

Frontend:
  • Vite for fast HMR dev, optimized production builds
  • PWA manifest.json enables installation on mobile
  • Context API for auth state; hooks for data fetching
  • Tailwind CSS for styling; custom ui/ components compose primitives
  • Mobile-first responsive design via Tailwind breakpoints

Root:
  • docker-compose.yml spins up Postgres + (optional Redis)
  • Root package.json has shared scripts: "dev" (start both), "test" (run all tests)
  • .env.example + .env.example in client/ and server/ show required variables
  • .gitignore excludes node_modules, .env, dist, build, coverage, .DS_Store, etc.
